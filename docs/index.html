Cinco instrucciones

Todo el taller se reduce a esto. En el servidor:

// socket = ESE cliente en particular
io.on('connection', (socket) => { ... })

socket.on('evento', (data) => { ... })  // escuchar a ese cliente
socket.emit('evento', data)             // mandarle solo a él
socket.broadcast.emit('evento', data)   // a todos MENOS a él
io.emit('evento', data)                 // a TODOS

En el navegador:

const socket = io();                    // abre la conexión
socket.emit('evento', data)             // mandar al servidor
socket.on('evento', (data) => { ... })  // escuchar al servidor
La regla de oro

El cliente manda solo el texto. El autor lo pone el servidor. Si confías en el autor que manda el cliente, cualquiera escribe haciéndose pasar por otro desde la consola del navegador. Vale 10 puntos de la rúbrica.

Once huecos, en orden

Los retos

Cada uno está marcado con TODO en server.js y en public/client.js. Hazlos en orden y prueba después de cada uno.

  1. Entrar con un nombre
    El cliente emite entrar. El servidor lo guarda en el Map usando socket.id como llave y avisa a todos.
    PruebaAl entrar la segunda ventana, en la primera aparece «Luis se unió al chat».
  2. Mandar y recibir mensajes
    El cliente emite mensaje con el texto. El servidor arma { autor, texto, hora } y lo reparte con io.emit.
    PruebaEscribes en una ventana y aparece en las dos al instante.
  3. Lista de conectados
    Cuando alguien entra o sale, el servidor manda io.emit('usuarios', [...usuarios.values()]).
    PruebaLos dos nombres aparecen en ambas ventanas.
  4. «Fulano está escribiendo…»
    Aquí va socket.broadcast.emit, no io.emit. Con io.emit te verías a ti mismo escribiendo.
    PruebaLuis lo ve cuando Ana teclea, y Ana no se ve a sí misma.
  5. Salir bien
    En socket.on('disconnect') borras al usuario del Map, avisas y mandas la lista actualizada.
    PruebaCierras una ventana y desaparece de la lista de la otra.

Trampas típicas

SíntomaCausa
io is not definedFalta el <script src="/socket.io/socket.io.js">, o va después de client.js.
El mensaje llega dos vecesPusiste el socket.on dentro de otro listener, así que se registra de nuevo en cada evento.
Me veo a mí mismo escribiendoUsaste io.emit en vez de socket.broadcast.emit.
Funciona en mi PC, no entre dosEl cliente apunta a localhost. Usa io() sin argumentos.
Quedan usuarios fantasmaFalta el disconnect, o borras del Map por nombre en vez de por socket.id.
EADDRINUSEYa tienes un servidor en el 3000. Ciérralo o cambia el puerto.
Un compañero rompe la páginaPintaste con innerHTML en vez de textContent.
